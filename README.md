# MUZPETRO.shop — концепция редизайна

Адаптивный макет на чистом HTML, CSS и JavaScript по предоставленному референсу. Сборка и сторонние JavaScript-библиотеки не нужны. Все изображения и шрифты сохранены локально.

## Запуск

Откройте `index.html` в браузере или запустите из этой папки:

```powershell
python -m http.server 8080 --bind 127.0.0.1
```

Адрес: http://127.0.0.1:8080

## Файлы

- `index.html` — структура страницы и модальные окна.
- `styles.css` — оформление, адаптация для телефона и планшета.
- `script.js` — товары, поиск, фильтры, сортировка, карточки и корзина.
- `fonts.css`, `assets/` — локальные шрифты и изображения.

## Что работает

Поиск по названию и типу товара, фильтрация по разделам, сортировка по цене и названию, просмотр товара, добавление в корзину, изменение количества и удаление. Корзина сохраняется в localStorage, если он доступен. Кнопка WhatsApp открывает подготовленное сообщение, которое посетитель может проверить и отправить самостоятельно. Телефонные ссылки, карта, мобильное меню и диалоги работают с клавиатуры; диалоги закрываются Escape.

Каталог содержит шесть демонстрационных товаров с главной страницы исходного магазина. В разделе света показано приглашение обратиться к консультанту, поскольку в этой подборке световых приборов нет. Поиск и «Все товары» работают только с этой подборкой. Цены и наличие не синхронизируются с магазином. Заказы не отправляются на сервер, оплата не подключена. Действующий сайт не изменялся.

## Источники

### Анимация hero

При загрузке страницы фотография проявляется с небольшим приближением, три строки заголовка появляются последовательно, затем проявляются описание и кнопки. Красная точка завершает заголовок, а звуковая волна прорисовывается по линиям. Вся последовательность занимает около 1,7 секунды и не повторяется по кругу. Фотография постоянно перекрывает волну по диагональной границе.

Анимации работают на CSS и учитывают `prefers-reduced-motion`: при уменьшении движения всё содержимое видно сразу. Кнопка, получившая фокус с клавиатуры, появляется немедленно. Изображение hero предзагружается. Тайминги и ключевые кадры находятся в конце `styles.css`; параметры штрихов волны задаются в `script.js`.

### Мобильные категории

На экранах до 650 px четыре карточки категорий однократно проявляются с подъёмом на 20 px, когда входят в область просмотра. Длительность — 620 мс, задержка между карточками одной группы — 90 мс. После завершения классы анимации удаляются, наблюдение за карточкой прекращается. При `prefers-reduced-motion` и без JavaScript карточки сразу видны.
